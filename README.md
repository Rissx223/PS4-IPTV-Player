# PS4 IPTV Player

An IPTV player homebrew application for the PlayStation 4, built with the
[OpenOrbis PS4 Toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain).

It lets you browse and play IPTV content from three kinds of sources:

- **Xtream API** (IPTV panel login) — host + username + password
- **M3U URL** — a remote extended-M3U / M3U8 playlist
- **Local playlist** — an `.m3u` file stored on the console (e.g. under `/data`)

The UI is rendered with SDL2 and navigated entirely with the DualShock 4. Video
is decoded by the PS4's hardware decoder via `libSceAvPlayer`.

![app icon](sce_sys/icon0.png)

## Codec support

The PS4 has a fixed-function video decoder. In practice it decodes **AVC
(H.264)** and **HEVC (H.265)** only. AV1, VP9 and VVC (H.266) have **no PS4
hardware decode block** and cannot be decoded in real time in software on this
hardware.

The app keeps a single codec table (see `include/codec.h`) so it can show
accurate capability information instead of failing silently:

| Codec | PS4 support        | Notes                                   |
|-------|--------------------|-----------------------------------------|
| H.264 | ✅ Hardware        | AVC via `libSceAvPlayer` / Videodec2    |
| H.265 | ✅ Hardware        | HEVC via `libSceAvPlayer` / Videodec2   |
| AV1   | ❌ Not supported   | No hardware decoder on PS4              |
| VP9   | ❌ Not supported   | No hardware decoder on PS4              |
| VVC   | ❌ Not supported   | No hardware decoder on PS4              |

Channels are tagged with a codec badge in the browser. Selecting a channel
whose codec is unsupported shows a clear message rather than a black screen. The
codec layer is pluggable, so if a future decode path becomes available it can be
wired in without touching the rest of the app.

## Building

Prerequisites:

- The OpenOrbis PS4 Toolchain, with the `OO_PS4_TOOLCHAIN` environment variable
  pointing at it.
- `clang` / `clang++` / `ld.lld` version 18 on the host `PATH`.
- The toolchain's `PkgTool.Core` requires OpenSSL 1.1 at runtime.

```sh
export OO_PS4_TOOLCHAIN=/path/to/OpenOrbis-PS4-Toolchain
make            # produces IV0000-IPTV00001_00-PS4IPTVPLAYER000.pkg
make clean
```

The build compiles everything under `source/`, links `eboot.bin`, generates
`sce_sys/param.sfo`, and packages a `.pkg` installable on a jailbroken PS4.

### Regenerating the icon and UI images

The app icon (`sce_sys/icon0.png`, 512×512) and the UI images under
`assets/images/` are generated by a script (requires Pillow):

```sh
python3 tools/gen_assets.py
```

| D-pad / stick | Navigate                                           |
| ✕ Cross       | Select / confirm / play / pause                    |
| ◯ Circle      | Back / stop playback / exit (from home)            |
| ▢ Square      | Edit source (home) / backspace (keyboard)          |
| △ Triangle    | Delete source (home) / toggle overlay (player)     |


## How playback works

1. A source is loaded into a `Playlist` (Xtream API calls, an M3U download, or a
   local file).
2. Selecting a channel resolves its playback URL and classifies its codec.
3. `VideoPlayer` initialises `libSceAvPlayer`, which demuxes the container
   (TS / MP4 / HLS over HTTP/HTTPS or a local file) and drives the hardware
   decoder.
4. Decoded NV12 frames are colour-converted to ARGB8888 and blitted by the SDL
   renderer, letter-boxed to preserve aspect ratio.

## Notes / limitations

- This is homebrew and requires a jailbroken PS4 to install and run.
- TLS certificate verification is intentionally relaxed because many IPTV panels
  ship self-signed certificates (mirrors common IPTV clients).
- Remote channel logos are not downloaded yet; a placeholder thumbnail is shown.
- Software NV12→ARGB conversion at 1080p is CPU intensive; this is a reference
  implementation prioritising clarity.
